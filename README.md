# OLVM Report Generator

Generate a clean, printable PDF inventory report that summarizes your OLVM/oVirt Engine datacenter: Datacenters, Clusters, Hosts, Storage Domains, Networks, and Virtual Machines (VM NICs, Guest IPs, Virtual Disks) plus CPU/Memory/Storage utilization.

---

## 💡 Highlights

- **One‑Click PDF**: OLVM/oVirt Engine inventory report
- **Cover‑Style Header**: Infrastructure Report with your logo
- **Summary**: Resource counts at a glance
- **Total Utilization**: CPU/Memory/Storage
- **Per‑Host Utilization**: CPU & Memory used per host
- **Datacenters**: ID, Status
- **Clusters**: Datacenter, CPU Architecture/Type, Version
- **Hosts**
  - CPU Model, Sockets, Cores, Memory
  - Network Speed (Fastest NIC)
  - Product Name & Serial Number
- **Storage Domains**: Domain/Storage Type, Datacenter, Used/Available
- **Networks**: VLAN, MTU, Datacenter
- **Virtual Machines**
  - Host, Status, OS Type, CPU Topology, Memory
  - Virtual NICs (MAC, vNIC profile, Network, VLAN)
  - Guest IP Addresses
  - Virtual Disks (Name, Size, Storage Domain)
- **Footer**: `Generated By <Name>` + `Page X/Y` on every page

- Python **3.8+**
- Require Packages List
  - `requests`
  - `reportlab`
  - `pillow`

pip install requests reportlab pillow

## 📝 Usage

```
Usage: OLVMReportGenerator.py [-h] --engine ENGINE [--user USER] --password PASSWORD [--output OUTPUT]
                              [--insecure] --name NAME [--platform NAME] --logo FILE [--timeout TIMEOUT]
```

Generate a PDF inventory report from OLVM/oVirt Engine.

Options:
```
  -h, --help           Show this help message and exit
  --engine ENGINE      Engine domain, e.g. olvm.engine.local
  --user USER          Engine user (default: admin@internal)
  --password PASSWORD  Engine password (shown on the command line)
  --output OUTPUT      Output PDF path (default: <engine>_report_<date>.pdf)
  --insecure           Skip SSL certificate verification (self-signed certs)
  --name NAME          Name shown as 'Generated By' in the footer, e.g. "Aung Thu Myint"
  --platform NAME      Platform display name (default: "Oracle Linux Virtualization Manager")
  --logo FILE          Logo image placed in the top-left of the header (PNG recommended, e.g. 300x300 pixels)
  --timeout TIMEOUT    HTTP timeout in seconds (default: 60)
```

> **Note:** OLVM engines typically use a self-signed certificate, so you will usually need `--insecure`.

## 📝 Usage Command Example

```
OLVMReportGenerator.py --engine olvm.engine.local --password "xxxxx" --insecure --name "Aung Thu Myint" --logo "Path\To\Logo.png"
```

## 🎯 Output PDF File

The PDF Includes:

- **Infrastructure Report Header** (Logo, Platform, Engine Domain)
- **Summary**
- **Total Utilization**
- **Per‑Host Utilization**
- **Datacenters**
- **Clusters**
- **Hosts**
- **Storage Domains**
- **Networks**
- **Virtual Machines** (VM NIC + Guest IP + Virtual Disks)

On Success CLI Prints:

```
Report File Name [olvm.engine.local_report_20260901_164226.pdf]
Report generated successfully.
```
